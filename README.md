# Portfolio Safra

## Introdução

Este portfólio é um tributo à excelência e ao legado do Banco Safra. Desenvolvi esta apresentação pessoal como um manifesto do meu desejo de construir uma carreira em uma das instituições mais respeitadas do segmento de Private Banking no Brasil.

## Conclusão

Criei este projeto não apenas com o intuito de demonstrar minhas habilidades técnicas, mas como uma demonstração do meu compromisso em gerar valor através da tecnologia. Meu objetivo é transformar linhas de código em soluções que reflitam o padrão de qualidade e a segurança que os clientes Safra esperam e merecem.

## Tecnologias

+ Typescript
+ Angular
+ TailwindCSS
